Strategy Design Pattern
-----------------------

* There is a SimUDuck Application which is designed by OO Programmer.
* Now there is a requirement from client that every 6 months they are adding new functionality.
  so use strategy pattern and update code such that when new behavior or feature added there is no change in logic.
